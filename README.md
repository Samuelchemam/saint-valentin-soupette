# saint-valentin-soupette

## Recettes glacées 🍨

`recettes.html` — Module 1 : gestion des recettes (crème glacée, gelato, sorbet, milkshake).

- CRUD complet, catégorisation, tags libres, recherche/filtre
- Base d'ingrédients de référence (% gras / % sucre / % solides totaux pour 100g), éditable
- Macros auto-calculées quand les ingrédients d'une recette matchent la base de référence
- Pré-rempli avec 3 recettes (Noisette-Poire-Nutella, Pêche Melba, clone Magnum Starchaser) — quantités à compléter
- Persistance en `localStorage`, export/import JSON pour backup

Modules suivants (à venir) : Module 2 — calculateur de base (cibles gras/sucre/solides par type de préparation), Module 3 — générateur d'idées.
